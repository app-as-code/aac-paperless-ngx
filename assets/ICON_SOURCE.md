# Icon source

The icon is downloaded from the dashboard-icons collection (repository
`homarr-labs/dashboard-icons`, served via jsdelivr). No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/paperless-ngx.svg` | Default logo |

Download URL:

- https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/paperless-ngx.svg

License of the icon collection: Apache-2.0 (repository `homarr-labs/dashboard-icons`).

No light or dark variant is available in the collection, so only the default logo is
provided. The logo is a single dark green color and may have low contrast on dark
backgrounds.

The Paperless-ngx logo itself is the property of the Paperless-ngx project
(https://github.com/paperless-ngx/paperless-ngx, GPL-3.0 for the software). Trademark and
